How it works

01

Real facts, not guesses

Every finding comes from PyPI or the Python parser. No LLM decides whether a package exists.

02

Knows the tricky names

cv2 is opencv-python, PIL is Pillow. Standard library, local modules and optional imports are never flagged.

03

Built for agents

The same engine runs as an MCP server and an Agent Skill, so the agent checks its own change and fixes every BLOCK before it says "done".
